# 灵犀市场洞察 — 扣子工作流集合

本文件夹包含「灵犀市场洞察」项目的所有功能模块工作流，每个工作流都可以直接导入到**扣子(Coze)平台**使用。

## 📁 文件夹结构

```
灵犀工作流/
├── 01_导购助手/          (4个工作流)
│   ├── 01_智能导购主流程.json     — AI购物助手核心流程 (SPADE框架)
│   ├── 02_商品对比工作流.json     — 多商品多维对比分析
│   ├── 03_评价分析工作流.json     — 评价聚合与可信度分析
│   └── 04_营销内容生成工作流.json — 多平台营销内容一键生成
│
├── 02_运营中心/          (5个工作流)
│   ├── 01_新闻瀑布流.json         — 多平台电商实时动态采集
│   ├── 02_智能选品推荐.json       — 基于预算+平台的选品分析
│   ├── 03_客服话术生成.json       — 4种客服场景话术模板
│   ├── 04_定价策略分析.json       — 科学定价+利润优化
│   └── 05_运营问答.json           — 电商运营知识问答
│
├── 03_市场监测/          (4个工作流)
│   ├── 01_市场趋势分析.json       — 热销品类+消费趋势
│   ├── 02_竞品分析.json           — 深度竞品SWOT分析
│   ├── 03_每日运营报告.json       — 自动化日报生成
│   └── 04_政策新闻监控.json       — 平台政策变化监控
│
└── 04_小红书发布/        (4个工作流)
    ├── 01_AI文案生成.json         — 图片识别+多套文案生成
    ├── 02_智能发布代理.json       — 内容合规+自动发布
    ├── 03_账号管理.json           — 账号连接+健康监控
    └── 04_后台优化器.json         — 定时优化+自动续登
```

## 🚀 使用方法

1. 打开扣子平台：https://www.coze.com
2. 创建新的 Bot 或 Workflow
3. 选择「导入」功能
4. 上传对应的 `.json` 工作流文件
5. 配置知识库和插件（按工作流内的配置说明）
6. 调试并发布
