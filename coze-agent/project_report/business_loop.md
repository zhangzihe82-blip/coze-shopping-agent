# 灵犀导购 - 业务闭环设计

> 更新时间：2026-05-27

## 核心定位

灵犀导购不是通用购物推荐工具，而是一个**店铺专属的AI导购 + 自动化营销系统**。帮助客人选购**我方店铺内的商品**，同时自动在社交媒体发布内容引流，形成完整商业闭环。

## 业务闭环

```
┌─────────────────────────────────────────────────────┐
│                   灵犀导购 业务闭环                    │
│                                                       │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐       │
│   │  内容引流  │───→│  智能导购  │───→│  成交转化  │       │
│   │ (小红书/抖音)│   │ (店铺助手) │   │ (店铺成交) │       │
│   └──────────┘    └──────────┘    └──────────┘       │
│        ↑                               │              │
│        └────────── 数据反馈 ───────────┘              │
└─────────────────────────────────────────────────────┘
```

## 三大核心模块

### 一、内容引流层（Content & Traffic）

自动在社交媒体平台发布内容，吸引潜在客户进入店铺。

#### 1.1 小红书笔记自动发布

| 功能 | 说明 |
|------|------|
| 内容生成 | AI 根据店铺商品自动生成种草笔记（标题+正文+话题标签） |
| 图片生成 | AI 生成商品搭配图、使用场景图 |
| 定时发布 | 支持内容日历，定时自动发送 |
| 互动管理 | 自动回复评论、私信引导到店 |
| 数据追踪 | 笔记曝光、点赞、收藏、评论、转化统计 |

**内容类型：**
- 🌿 好物推荐/种草笔记
- 📦 开箱测评
- 💡 使用教程/搭配指南
- 🔥 热点话题蹭流量
- 🎁 福利活动/优惠预告

#### 1.2 抖音短视频自动发布

| 功能 | 说明 |
|------|------|
| 脚本生成 | AI 根据商品生成短视频口播脚本 |
| 视频制作 | 商品图片/视频素材自动剪辑成短视频 |
| 自动发布 | 调用抖音开放平台API定时发布 |
| 话题运营 | 自动匹配热门话题、BGM推荐 |
| 数据追踪 | 播放量、点赞、评论、分享、转化 |

**内容类型：**
- 🎬 商品展示（15-30秒快节奏）
- 📖 知识科普（行业干货引流）
- 🎯 场景短剧（产品植入）
- 💬 用户证言/评价合集

### 二、智能导购层（Shopping Assistant）

店铺专属AI导购，帮助进店客人快速找到合适商品。

#### 2.1 店铺商品库

```
店铺商品数据库
├── 商品名称 / SKU
├── 价格 / 库存
├── 规格 / 参数
├── 图片 / 视频
├── 使用场景标签
├── 适用人群标签
├── 关联搭配推荐
└── 用户评价摘要
```

#### 2.2 导购对话能力

| 能力 | 说明 |
|------|------|
| 需求探询 | 多轮对话了解客户场景、预算、偏好 |
| 商品推荐 | 从店铺商品库中精准匹配 |
| 对比讲解 | 店铺内同类商品横向对比 |
| 搭配建议 | 跨品类关联推荐，提升客单价 |
| 促销引导 | 结合店铺活动自动推荐优惠方案 |
| 异议处理 | 解答客户疑虑，促成下单 |

#### 2.3 区别于通用导购

| | 通用导购（旧版） | 店铺导购（新版） |
|------|------|------|
| 商品来源 | 全网搜索 | **自家店铺商品库** |
| 推荐目的 | 帮用户找到最好的 | **帮客人找到最合适的 + 促成下单** |
| 利润导向 | 无 | **在用户满意前提下最大化店铺收益** |
| 库存感知 | 无 | **实时库存，不推荐缺货款** |
| 话术风格 | 客观评测 | **客观 + 适度引导成交** |

### 三、成交转化层（Conversion）

#### 3.1 导购→成交衔接
- 对话中直接生成商品卡片/链接
- 一键加入购物车引导
- 限时优惠紧迫感营造
- 订单催付提醒

#### 3.2 售后与复购
- 购买后自动跟进（使用教程、保养建议）
- 复购提醒（消耗品补货、新品推荐）
- 老客户专属优惠

## 数据闭环

```
引流数据 ─→ 哪些内容带来了最多客人？
  │
导购数据 ─→ 客人最常问什么？哪些商品咨询最多？
  │
成交数据 ─→ 哪些商品转化最好？客单价多少？
  │
反馈 ──→ 优化内容策略 + 调整商品推荐权重
```
